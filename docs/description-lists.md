## Too-vague descriptions

The same for all departments. An entry with one of these descriptions cannot be saved: a clear message explains why and suggests the department's common descriptions.

- Copia
- Copias
- Fotocopia
- Fotocopias
- Documento
- Documentos

The comparison ignores capital letters, accents and surrounding spaces, so "COPIAS" or " copias " are also blocked.
